# RandevuAI — Demo

Randevu sistemli, yapay zekâ destekli cevap sistemine sahip modern ve responsive web sitesi demosu. Saf **HTML + CSS + JavaScript** ile yazılmıştır, herhangi bir bağımlılık gerektirmez.

## Özellikler
- 📅 Online randevu formu (tarih + saat seçimi, doğrulama)
- 🤖 Yapay zekâ destekli demo sohbet asistanı (anahtar kelime tabanlı yanıtlar)
- 📱 Tamamen responsive (mobil menü dahil)
- 🎨 Modern koyu tema, degrade vurgular, yumuşak animasyonlar
- ⚡ Kurulum gerektirmez — tek dosya aç, çalışır

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Hepsi bu.

## Dosyalar
- `index.html` — sayfa yapısı
- `styles.css` — tasarım ve responsive düzen
- `script.js` — randevu formu, mini takvim ve AI asistan mantığı
